# Kompakte filmforslag

Både manuelle søkeresultater og forslag fra coveranalyse viser nå kun:

- coverbilde
- originaltittel
- utgivelsesår
- handlingen «Bruk»

Alternativ tittel, IMDb-score, IMDb-lenke, matchgrunnlag og beskrivelse er fjernet fra selve forslagskortene. Metadataene beholdes fortsatt i resultatobjektet og fylles inn når brukeren velger «Bruk».
